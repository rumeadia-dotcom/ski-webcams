# 스키장 웹캠

국내 스키장의 실시간 웹캠과 날씨를 한곳에서 보는 모바일 웹입니다.

- 사이트 안에서 재생: 모나용평, 휘닉스파크, 웰리힐리파크, 지산포레스트, 알펜시아, 오크밸리
- 공식 웹캠 페이지로 연결: 곤지암, 하이원, 무주덕유산, 오투리조트, 엘리시안 강촌, 비발디파크
- 즐겨찾기한 스키장은 목록 상단에 표시됩니다(브라우저에 저장).
- 날씨: 현재 기온·강수량과 지난 3일·앞으로 3일 예보 ([Open-Meteo](https://open-meteo.com/), CC BY 4.0)

영상은 각 스키장이 공개한 웹캠이며, 이 사이트는 영상을 저장하거나 중계하지 않습니다.

## 개발

빌드 도구가 없는 정적 사이트입니다.

```
npm start   # http://localhost:5173
npm test    # Node 내장 테스트 러너
```

스키장과 카메라는 `js/data.js` 에서 관리합니다.
